# Sources used for the adaptation

- User-provided Tencent Meeting recording:
  <https://meeting.tencent.com/crm/Knnggd6oc7>
- Official Tianyi 2.0 product page:
  <https://www.x-humanoid.com/detail/tianyi.html>
- Official X-Humanoid SDK examples:
  <https://github.com/Open-X-Humanoid/xhumanoid_sdk>
- Official single-joint ROS 2 command example:
  <https://github.com/Open-X-Humanoid/xhumanoid_sdk/tree/main/single_joint_control>

The public SDK example is explicitly documented for TianGong 3.0, so its ROS 2
contract is treated as a candidate Tianyi adapter, not as proof of compatibility.
