# Tianyi 2.0 PICO Teleoperation

This repository is being built as an independent PICO teleoperation stack for the
X-Humanoid Tianyi 2.0 wheeled dual-arm robot.

The first repository revision intentionally contains only the previous Unitree G1
implementation, preserved under [`legacy/g1_holoteleop`](legacy/g1_holoteleop).
It is a code-only baseline used for provenance and comparison; it is **not** the
Tianyi implementation.

See [`BASELINE_G1.md`](BASELINE_G1.md) for the exact meaning and exclusions of the
baseline snapshot.
